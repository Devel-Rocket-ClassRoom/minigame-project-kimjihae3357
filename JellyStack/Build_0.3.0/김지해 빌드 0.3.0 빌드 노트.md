# 빌드 노트
## v0.3.0

정리 기준: 2026년 5월 29일 13:00 이후 커밋 내역

## 주요 추가 기능

- 세이브/로드 기능을 구현했음.
  - 카드 데이터베이스, 저장 데이터, 저장 매니저, 저장 시스템을 추가
  - 일차, 날씨, 카드, 코인 등 주요 진행 상태가 저장/복원되도록 관련 매니저와 UI를 연동했음.
- 타이틀 씬 추가
- CoinPoket을 구현해 보유 코인을 별도 오브젝트로 관리할 수 있게 함
- 채집 결과 랜덤 시스템을 추가함
- 적 포탈 및 전투 관련 기능을 보완했음
- 카드 간 제약 사항을 추가함
- 카드 최대 보유 개수 관리 기능을 구현
- 시간 조절 Slider와 날씨 아이콘 표시 기능을 추가함
- 카드 오픈, 적 등장 등 일부 이펙트 연출 추가

## 변경된 내용

- GameManager 구조를 개편했음.
  - 날씨 시스템과 적 스폰 시스템의 등장 주기 관리를 GameManager 쪽으로 이전했음.

## 콘텐츠 및 밸런스

- 신규 카드 데이터와 아이콘을 추가했음.
  - 건물: Dark Portal, Smelter, Storage, Workshop
  - 자원/가공품: Brick, Campfire, Diamond, Gold Ore, Gold Bar, Iron Ore, Iron Bar, Silver Ore, Silver Bar, Plank
  - 채집원: Logging Camp, Mine, Quarry
- 신규 레시피 데이터를 추가했음.
  - Brick, Dark Portal, Gold Bar, Gold Key, Iron, Logging Camp, Plank, Quarry, Silver Bar, Storage 등
- 카드팩 구성과 가격 표시 UI를 조정했음.
  - StarterPack, AdventurePack, RandomPack 계열 데이터와 구매 포인트를 수정했음.
- 주민, 자원, 채집원, 적 카드 데이터 일부를 조정했음.
- 카드 이미지와 카드 아이콘을 대량 추가/교체해 카드 종류별 시각 구분을 강화했음.
