# 빌드 노트
## v0.2.0

## 주요 추가 기능

- Day 사이클과 날짜 전환 UI가 추가되었습니다.
- 하루가 끝날 때 주민에게 식량을 공급하는 Feed Time 시스템이 추가되었습니다.
- 식량 부족, 주민 전멸 등에 따른 게임오버 처리가 추가되었습니다.
- 코인 기반 상점 시스템이 추가되었습니다.
  - 카드 판매 기능
  - 카드팩 구매 기능
- 확률 기반 카드팩 시스템이 추가되었습니다.
  - Adventure Pack
  - Villager Pack
  - 앞으로 나올 카드팩들
- 적 카드와 전투 시스템이 추가되었습니다.
  - 적카드가 주민카드 추적
  - Battle Point 전투
  - 공격/피격 연출
  - 적 처치 시 아이템 드랍
- 날짜 기반 적 스포너와 포탈 소환 연출이 추가되었습니다.
- 날씨 시스템이 추가되었습니다.
  - Sunny: 채집 보상 2배 확률
  - Rain: 채집 속도 증가
  - Snow: 랜덤 2장 카드 빙결(상호작용 금지)
  - Storm: 랜덤 3장 카드 흔들림 및 랜덤 1장 제거
- 레시피 창 더미 UI 추가
- 판매 포인트에 마우스 오버 시 판매 가격을 미리 볼 수 있는 팝업 UI 추가

## 변경된 내용

- 채집 구조가 `SourceCardData` 기반으로 변경되어 채집물마다 결과물, 수량, 시간을 따로 설정할 수 있게 되었습니다. 
(같은 레시피 구조 -> 채집물 전용구조)
- 카드 데이터에 판매 가격과 판매 가능 여부가 추가되었습니다.
- 주민 데이터에 체력, 배고픔, 공격력, 작업 속도, 공격 간격 정보가 추가되었습니다.
- 카드팩 구조가 고정 구성 카드팩(스타터팩)과 랜덤 확률 카드팩(나머지 카드팩)으로 분리되었습니다.

## 콘텐츠 및 밸런스

- 신규 카드가 추가되었습니다.
  - 동전, 하트, 아기, 불의 주민, 물의 주민, 돌의 주민, 적, 보물상자, 황금키, 텃밭
- 신규 레시피가 추가되었습니다.
  - 회복, 아기, 집, 보물, 텃밭, 채집
- 스타터팩, Adventure Pack, Villager Pack 구성이 조정되었습니다.
- 채집, 제작, 회복, 아기 생성 등 주요 작업 시간이 조정되었습니다.
- 주민별 체력, 공격력, 작업 속도, 판매 가격이 조정되었습니다.
